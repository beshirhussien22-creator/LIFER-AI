### Installation
Truly published and installable on any device. Access at lifer.ai.com or search for "LIFER AI".

### Setup for Development
1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Set up your OpenAI API key in a `.env` file:
   ```
   OPENAI_API_KEY=your_actual_api_key_here
   ```

3. Run the chatbot:
   ```
   streamlit run app.py
   ```

4. Access the web interface, login, and start using the ultimate AI.
